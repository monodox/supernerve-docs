# Roadmap

> The nervous system doesn't stop growing. Here's where we're headed.

---

## 🟢 Phase 1 — Foundation (Q2 2026) ✅

*Build the core nervous system.*

- [x] Agent framework (6 agent types)
- [x] Skills engine (7 core skills)
- [x] Connector architecture (4 integrations)
- [x] Workflow engine with triggers and steps
- [x] REST API with authentication
- [x] AWS deployment (Lambda + ECS)
- [x] TypeScript SDK
- [x] Documentation site

---

## 🔵 Phase 2 — Sensory Expansion (Q3 2026)

*More inputs. More awareness. More intelligence.*

- [ ] **New Connectors** — Jira, Linear, Confluence, Microsoft Teams, Salesforce
- [ ] **Redis & PostgreSQL connectors** — Direct data layer access
- [ ] **Webhook builder** — Visual webhook configuration
- [ ] **Agent-to-agent communication** — Agents that delegate and collaborate
- [ ] **Streaming responses** — Real-time output for long-running tasks
- [ ] **Python SDK** — Full parity with TypeScript
- [ ] **Plugin system** — Community-built skills and connectors

---

## 🟣 Phase 3 — Self-Optimization (Q4 2026)

*The system starts improving itself.*

- [ ] **Adaptive workflows** — Workflows that rewrite their own steps based on outcomes
- [ ] **Learning memory** — Agents that improve from past interactions
- [ ] **Performance analytics** — Built-in observability for agent behavior
- [ ] **A/B workflow testing** — Run workflow variants and auto-select winners
- [ ] **Natural language workflow builder** — Describe what you want, get a workflow
- [ ] **Cost optimization engine** — Automatically route to cheapest viable model

---

## 🟡 Phase 4 — Autonomy (Q1 2027)

*From reactive to proactive. The system acts before you ask.*

- [ ] **Proactive agents** — Agents that identify problems and act without prompting
- [ ] **Cross-org intelligence** — Anonymized pattern sharing across deployments
- [ ] **Self-healing workflows** — Automatic error recovery and rerouting
- [ ] **Interface generation** — Agents that build their own UIs
- [ ] **Governance framework** — Guardrails, audit trails, and compliance automation
- [ ] **Multi-cloud deployment** — GCP, Azure, self-hosted Kubernetes

---

## 🔴 Phase 5 — The Living Enterprise (Q2 2027)

*Software that evolves like an organism.*

- [ ] **Organizational memory** — Institutional knowledge that never gets lost
- [ ] **Predictive workflows** — Anticipate needs based on patterns
- [ ] **Dynamic role adaptation** — Interfaces that reshape per user context
- [ ] **Federated agents** — Agents that span organizational boundaries
- [ ] **Zero-config onboarding** — New employees get a personalized nervous system on day one

---

## How We Prioritize

1. **User pain** — What's blocking people right now?
2. **Ecosystem leverage** — What unlocks the most downstream value?
3. **Technical foundation** — What makes future work easier?
4. **Community signal** — What are people asking for?
