# Code of Conduct

## The supernerve Principle

We're building a system that adapts, learns, and evolves. Our community should do the same. This code of conduct isn't a rulebook — it's the operating system for how we collaborate.

## Our Standards

### Signals We Amplify ⚡

- Empathy and kindness in every interaction
- Constructive feedback that builds people up
- Respect for differing viewpoints and experiences
- Graceful acceptance of responsibility for mistakes
- Focus on what's best for the community, not just the individual

### Signals We Dampen 🔇

- Harassment, trolling, or personal attacks
- Discriminatory language or imagery
- Publishing others' private information without consent
- Sustained disruption of discussions or contributions
- Any conduct that would be inappropriate in a professional setting

## Scope

This code applies everywhere supernerve lives — GitHub, Discord, forums, events, and any space where you represent the project.

## Enforcement

### Reporting

Instances of unacceptable behavior can be reported to:

**conduct@monodox.com**

All reports are reviewed confidentially and promptly.

### Response Ladder

1. **Correction** — Private conversation, clarification of expectations
2. **Warning** — Formal notice with defined consequences for continued behavior
3. **Temporary Ban** — Removal from community spaces for a defined period
4. **Permanent Ban** — Permanent removal from all community spaces
