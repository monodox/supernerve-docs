# Introduction

Welcome to **supernerve** — an AI-powered agent platform that lets you build, deploy, and orchestrate intelligent agents with skills, connectors, and workflows.

## What is supernerve?

supernerve provides a unified framework for creating AI agents that can reason, remember, connect to external services, and execute complex workflows autonomously.

## Key Concepts

- **Agents** — Autonomous AI entities with memory, skills, and connectors
- **Skills** — Reusable capabilities like summarization, extraction, and classification
- **Connectors** — Integrations with external services (Slack, Notion, GitHub, etc.)
- **Workflows** — Multi-step orchestration pipelines with triggers and steps
