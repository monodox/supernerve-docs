# Libraries Overview

supernerve provides official SDKs and libraries for multiple languages.

## Official SDKs

| Library | Language | Install |
|---------|----------|---------|
| `@supernerve/sdk` | TypeScript/Node.js | `npm install @supernerve/sdk` |
| `supernerve` | Python | `pip install supernerve` |

## Community Libraries

Community-maintained libraries are available for other languages. Check the [GitHub organization](https://github.com/monodox) for the latest.

## SDK Features

- Agent creation and management
- Skill invocation
- Connector configuration
- Workflow orchestration
- Type-safe APIs (TypeScript)
