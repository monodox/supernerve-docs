# Installation

## Prerequisites

- Node.js 18+ or Python 3.10+
- An active supernerve account

## Node.js / TypeScript

```bash
npm install @supernerve/sdk
```

## Python

```bash
pip install supernerve
```

## Verify Installation

```bash
npx supernerve --version
# or
supernerve --version
```
